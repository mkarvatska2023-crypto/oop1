# Звіт до лабораторної роботи №6
## Тема: Розробка інтелектуальних агентів за допомогою Google ADK

###  Мета роботи
Навчитися створювати, конфігурувати та запускати ШІ-агентів на базі моделей Gemini, а також опанувати навички розгортання локальних веб-інтерфейсів для взаємодії з LLM.

---

### Виконання роботи

#### 1. Ініціалізація проекту
Проект було розгорнуто за допомогою фреймворку **Google Agent Development Kit (ADK)**. Для керування залежностями та віртуальним середовищем використано **Poetry**.

#### 2. Конфігурація та безпека
Для автентифікації агента використано файл `.env`, де збережено API-ключ від Google AI Studio. 

---

###  Результати
Агент успішно запущений та протестований у двох режимах:
1. **Консольний (CLI):** Пряма взаємодія через термінал.
2. **Веб-інтерфейс (GUI):** Запущено локальний сервер на порту `8000`, що дозволяє спілкуватися з ШІ через браузер.

```powershell
# Запуск веб-інтерфейсу
poetry run adk web --port 8000 
```
